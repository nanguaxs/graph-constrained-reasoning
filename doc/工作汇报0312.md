# 3月12日工作汇报

## 一、工作目标

本阶段工作的核心目标，是系统梳理项目中“图约束路径生成 + 推理 + 微调训练”的完整链路，并在代码阅读基础上，持续修复训练与推理中的关键问题，把原本偏实验性质的流程逐步整理成一个更稳定、可控、可复现的实验框架。

整体工作主要围绕以下四个方向展开：

1. 梳理图约束推理与路径生成机制。
2. 分析数据构建与评测流程。
3. 修复 `transformers` 升级后的兼容性问题。
4. 系统改造 `finetune` 微调训练框架，包括生成策略、奖励设计、日志体系和实验配置管理。

## 二、主要工作内容

### 1. 推理链路与图约束生成机制梳理

围绕 `qa_prompt_builder.py`、`graph_constrained_decoding.py`、`graph_constrained_decoding_model.py` 等模块，系统梳理了 prompt 构建、特殊 token 注入、trie 约束解码以及模型生成之间的协作关系。

重点明确了以下问题：

- 模型能够识别 `<PATH>`、`</PATH>`，本质上依赖于微调和推理阶段统一注册特殊 token，并保证 tokenizer 与 trie 中的 token 序列严格对齐。
- 图约束并不是全程生效，而是在模型进入 `<PATH> ... </PATH>` 区间后才真正启用，因此 prompt 末尾是否正确保留 `<PATH>`，以及 chat template 是否破坏该结构，会直接影响约束生成是否生效。
- `allow_tokens` 为空时的 fallback 逻辑，解释了模型为什么会在某些情况下走入 trie 的死胡同，或者出现约束失效问题。
- 推理阶段需要显式保证特殊 token 与微调阶段一致，并在 `</PATH>` 后及时停止生成，避免重复输出和边界污染。



### 2. 数据构建与评测流程梳理

对 `convert_cokg_qa.py`、truth path 搜索逻辑和评测函数进行了系统阅读，重点分析了：

- 子图构建方式；
- truth path 的搜索与多路径处理方式；
- 路径生成任务和最终答案任务之间的关系；
- 原有评估函数对“路径质量”和“答案命中”的耦合问题。

在此基础上，补充了纯路径评估视角，使评测不再只关注“最终答案是否正确”，而能够单独分析生成路径本身是否接近 ground truth。

这使训练效果分析更加细粒度，能够区分“路径没生成出来”“路径生成合法但未命中答案”“路径结构偏离真值”等不同问题。

### 3. 推理兼容性与框架升级适配

针对 `transformers` 升级后的变化，完成了一轮兼容性修复，主要包括：

- 量化参数的传递方式调整；
- 缺失 `generation_config.json` 时的兜底处理；
- 约束结束后重复生成 EOS 的停止逻辑修复。

这部分工作提升了项目在新版本依赖环境下的可运行性和稳定性，减少了由于底层框架升级带来的异常。

### 4. 微调训练框架系统性改造

这是本阶段工作的重点，主要包括以下几个方面。

#### 4.1 训练基础流程修复

- 修复了 `finetune/dataset.py` 中 `trie=None` 导致训练样本被整体跳过的问题。
- 清理了 `train.py` 中 `transformers` 的 dtype 弃用警告。
- 保存 LoRA 权重时显式保留 embedding 层，避免特殊 token 的 embedding 丢失。

这些改动保证了训练流程能够正确启动，并保留与 `<PATH>` 特殊 token 相关的必要参数。

#### 4.2 奖励函数重构

围绕 `finetune/reward.py`，对原有奖励设计进行了系统重构和增强，主要包括：

- 修复终点实体提取错误；
- 修复 hop 统计逻辑错误；
- 将路径文本先解析成结构化信息再打分，而不是只依赖字符串级比较；
- 新增路径结构匹配分 `R_path_match`；
- 将绕路惩罚改为相对 ground truth 的动态计算；
- 新增 loop 惩罚，降低模型生成绕圈路径、无效路径的概率；
- 将语义相似度从主项调整为辅助项，避免语义得分主导训练方向；
- 增加 embedding 缓存和接口调试信息，减少重复请求、提升可排障性。

目前奖励函数已经由单一粗粒度指标，升级为“答案命中 + 真值路径匹配 + 动态路径质量惩罚 + 语义辅助项”的复合设计，更贴合路径生成任务本身。

#### 4.3 日志体系与可观测性增强

新增统一日志工具，对训练、数据处理、生成、奖励计算等环节进行了分级日志替换，逐步用结构化日志取代原先零散的 `print`。

这项工作的效果是：

- 训练过程关键状态可观测；
- 调试信息可以按日志级别控制；
- 后续实验更容易复盘和比较。

#### 4.4 生成策略升级与重复路径问题治理

针对训练中路径重复率高、采样质量不稳定的问题，对 `finetune/grpo_trainer.py` 做了较大改造：

- 将原先固定采样扩展为多种可配置模式，包括 `sampling`、`beam`、`beam_sample` 和后续补入的 `group_beam_search`；
- 对 beam 类模式增加 `num_beams` 参数兜底修正；
- 引入补采样机制，在去重后不足 K 条时继续补生成；
- 增加 `max_resample_rounds` 控制补采样轮数；
- 为补采样后的变长序列补齐 `attention_mask`；
- 在 `generate_group_paths()` 中加入“按轮过滤已生成路径并重建 trie”的逻辑，从生成源头抑制重复路径，而不只是事后文本去重；
- 去掉无用的 `output_scores` 输出，减少不必要的生成开销和中间数据。

这部分工作显著增强了训练时候选路径的多样性和可控性，也为后续比较不同生成模式提供了基础。

#### 4.5 GPU 与实验配置管理完善

为了提升实验管理能力，补充和整理了训练配置：

- 新增 `gpu_id` 配置项，用于指定训练使用的 GPU；
- 在配置中对不同生成模式相关参数进行归类和标注，区分 beam、sample、group beam 各自适用的参数；
- 将模型保存路径改为按 `generation_mode`、`index_path_length` 等实验条件自动区分。

这样可以避免不同实验相互覆盖，也便于后续回溯结果来源。

#### 4.6 GT path 注入机制

针对“生成出的路径虽然都合法，但多条路径都无法命中答案，导致训练信号偏弱”的问题，新增了 GT path 预注入机制：

- 在正式采样前，先从 `ground_paths` 中选取 1~2 条真实路径加入候选集合；
- 注入后立即从 trie 中删除这些路径，再开始模型生成；
- 这样既能稳定提供有效监督信号，又能避免模型继续重复生成已注入的真值路径。

这项改动本质上把训练由“纯探索式生成”调整为“GT 引导 + 模型探索”的混合模式，有助于缓解训练初期奖励过弱、学习信号不稳定的问题。

#### 4.7 语义监督开关

为了支持更规范的对照实验，新增了 `use_semantic_reward` 配置项：

- 开启时，奖励函数包含 embedding 语义辅助项；
- 关闭时，不再调用 embedding 接口计算语义得分；
- 模型保存路径也按 `semantic_on` / `semantic_off` 自动区分。

这使得后续可以明确比较“是否引入语义监督”对训练效果的影响。

## 三、阶段性成果

通过这轮代码阅读和改造，项目在以下几个方面取得了明显提升：

- **机制更清楚**：理顺了图约束推理、prompt 结构、特殊 token、trie 解码和评测流程之间的关系。
- **训练更稳定**：修复了样本跳过、生成异常、奖励失真、重复路径过多等关键问题。
- **奖励更合理**：从粗粒度单指标，升级为更符合任务特征的结构化复合奖励。
- **实验更可控**：支持多种生成模式、GPU 指定、语义开关、分实验目录保存。
- **调试更方便**：建立了统一日志体系，提升了训练过程的可观测性和可复盘性。

总体来看，这一阶段已经把项目从“能跑通”逐步推进到“可分析、可配置、可复现实验”的工程化状态。

## 四、当前认识与问题思考

在当前框架下，虽然图约束保证了生成路径的合法性，但仍然存在一个关键现象：

- 某些样本中，模型虽然能够生成多条合法路径，但这些路径并不命中答案；
- 如果完全依赖模型自己探索，训练初期容易出现“奖励过弱”甚至“监督不足”的情况；
- 因此，引入 GT path 注入和可选语义监督，是为了在不破坏探索能力的前提下，提高训练信号质量。

这说明当前阶段的核心矛盾，已经从“路径是否合法”转向“合法路径是否足够接近目标答案、能否提供有效学习信号”。

## 五、后续工作建议

下一阶段建议重点围绕以下几个方向展开：

1. 增加训练统计指标，如命中率、GT 注入占比、无效样本占比、平均有效路径数等，进一步量化训练过程。
2. 系统比较不同生成模式（`sampling`、`beam`、`beam_sample`、`group_beam_search`）对路径质量和训练收敛的影响。
3. 比较开启/关闭语义监督时的效果差异，评估语义信号是否真正提升泛化能力。
4. 分析 GT path 注入比例对训练的影响，寻找探索与监督之间更合适的平衡点。
5. 继续优化路径去重与候选多样性机制，提高每轮训练中有效路径的覆盖率。
