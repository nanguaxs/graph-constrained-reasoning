# COKG_QA数据集转换工具使用说明

## 功能特性

### ✅ 核心功能

1. **多答案实体支持**
   - 自动为每个答案实体查找最短路径
   - 确保所有答案实体都包含在子图中
   - 不会因为找到一个答案就停止搜索

2. **最短路径优先**
   - 使用BFS算法查找从问题实体到每个答案实体的最短路径
   - 先添加最短路径，再扩展邻居节点
   - 最大搜索深度：5跳

3. **智能子图构建**
   - 第1步：添加问题→答案的最短路径
   - 第2步：添加问题实体的2跳邻居
   - 第3步：添加答案实体的2跳邻居
   - 邻居数限制：每个实体最多200个邻居

4. **详细统计信息**
   - 样本路径覆盖率：有多少样本找到了路径
   - 答案实体覆盖率：有多少答案实体找到了路径
   - 平均路径长度：路径包含的平均三元组数
   - 平均子图大小：子图包含的平均三元组数

## 使用方法

### 基本用法

```bash
cd d:/graph-constrained-reasoning
python src/gendata/convert_cokg_qa.py
```

### 输入文件

需要以下文件：
- `COKG_QA/KG/one_hop_KG.json` - 知识图谱文件（JSONL格式）
- `COKG_QA/QA/train.txt` - 训练集问答对
- `COKG_QA/QA/test.txt` - 测试集问答对
- `COKG_QA/QA/valid.txt` - 验证集问答对

### 输出文件

生成以下文件：
- `COKG_QA/cokg_qa_train.jsonl` - 训练集（500条）
- `COKG_QA/cokg_qa_test.jsonl` - 测试集（200条）
- `COKG_QA/cokg_qa_valid.jsonl` - 验证集（100条）

### 输出格式

每行一个JSON对象：
```json
{
  "id": "cokg_qa_train_1",
  "question": "问题文本",
  "answer": ["答案1", "答案2"],
  "q_entity": ["问题实体1"],
  "a_entity": ["答案1", "答案2"],
  "graph": [
    ["头实体", "关系", "尾实体"],
    ...
  ]
}
```

## 示例场景

### 场景1：单个答案实体

**输入：**
- 问题实体：`["北京"]`
- 答案实体：`["中国"]`

**处理：**
1. 查找 北京 → 中国 的最短路径
2. 添加 北京 的2跳邻居
3. 添加 中国 的2跳邻居

### 场景2：多个答案实体（不同距离）

**输入：**
- 问题实体：`["苹果公司"]`
- 答案实体：`["iPhone", "iPad", "MacBook"]`

**处理：**
1. 查找 苹果公司 → iPhone 的最短路径（假设1跳）
2. 查找 苹果公司 → iPad 的最短路径（假设2跳）
3. 查找 苹果公司 → MacBook 的最短路径（假设2跳）
4. **所有3个答案的路径都会被包含**
5. 再添加问题和答案实体的邻居

### 场景3：多个问题实体，多个答案实体

**输入：**
- 问题实体：`["张三", "李四"]`
- 答案实体：`["北京", "上海", "深圳"]`

**处理：**
1. 从 张三 查找到 北京、上海、深圳 的最短路径
2. 从 李四 查找到 北京、上海、深圳 的最短路径
3. **所有找到的路径都会被包含**
4. 再添加邻居节点

## 统计指标说明

### 样本路径覆盖率
- **定义**：有多少个样本至少找到了一条从问题到答案的路径
- **计算**：`(找到路径的样本数 / 总样本数) × 100%`
- **示例**：`92.0% (46/50)` 表示50个样本中有46个找到了路径

### 答案实体覆盖率
- **定义**：所有答案实体中有多少找到了从问题实体到它的路径
- **计算**：`(找到路径的答案数 / 总答案数) × 100%`
- **示例**：`87.5% (105/120)` 表示120个答案实体中有105个找到了路径

### 平均路径长度
- **定义**：最短路径包含的平均三元组数
- **示例**：`3.2` 表示平均每条路径包含3.2个三元组

### 平均子图大小
- **定义**：每个样本的子图包含的平均三元组数
- **示例**：`156.3` 表示平均每个子图包含156.3个三元组

## 配置参数

可以在 `main()` 函数中修改以下参数：

```python
# 样本数限制
max_samples = {
    'train': 500,  # 训练集样本数
    'test': 200,   # 测试集样本数
    'valid': 100   # 验证集样本数
}

# 在 convert_dataset() 调用中的参数
q_hops=2,           # 问题实体的跳数
a_hops=2,           # 答案实体的跳数
max_neighbors=200   # 每个实体的最大邻居数

# 在 find_shortest_paths_bfs() 中的参数
max_depth=5         # 最短路径的最大搜索深度
```

## 性能优化

1. **邻居数限制**：通过 `max_neighbors` 参数控制子图大小
2. **搜索深度限制**：通过 `max_depth` 参数避免过长的路径
3. **流式写入**：使用JSONL格式，边处理边写入，节省内存
4. **索引加速**：预先构建实体索引，加快查找速度

## 注意事项

1. **内存使用**：完整知识图谱会加载到内存中
2. **文件编码**：所有文件使用UTF-8编码
3. **路径保证**：如果答案实体在图中不存在或不可达，该答案不会有路径
4. **去重**：使用set自动去除重复的三元组
